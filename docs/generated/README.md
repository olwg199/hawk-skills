# Skill working records

Skills maintain these generated working records. Humans may read them to
understand project knowledge, plans, decisions, verification, and work history.
Current source and project instructions take precedence over stored notes.

- [Hawk Build project knowledge](hawk-build/project.md)
- Hawk Build design notes: `hawk-build/design/`, created when needed.
- Hawk Build task records: `hawk-build/builds/`; the skill creates its history
  index there when recording new work.
- Mobile UI Builder conventions: `hawk-mobile-ui-builder/project.md`, created
  when that skill saves project-specific UI knowledge.

Storage was moved from `.codex/` memory and `.build/` history. Existing record
content, IDs, and historical path mentions are preserved. Old paths inside
completed records describe the project at that time; they are not current
placement instructions. See [human documentation](../README.md) for navigation.
